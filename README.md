## Descripción

Este proyecto consiste en un sistema básico de registro y control de productos desarrollado en Java para la microempresa Bodega "Don Pepe".

El sistema permite mostrar la información de un producto, aumentar y reducir su stock, y validar que las operaciones de stock sean correctas mediante un menú por consola.

## Instrucciones de ejecución

1. Clonar o descargar el repositorio.
2. Abrir el proyecto en un IDE compatible con Java.
3. Ejecutar la clase `Main.java`.
4. Utilizar el menú de opciones mostrado en la consola.
